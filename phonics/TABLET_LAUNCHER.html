📱 平板 QR Code 啟動器

筆電負責提供離線教材，iPad 只要和筆電連在同一個 Wi‑Fi／行動熱點，再用相機掃下面的 QR Code 即可。

1
連到同一個網路
iPad 與這台 Windows 筆電需使用同一個 Wi‑Fi，或讓 iPad 連到筆電的「行動熱點」。
2
掃 QR Code
用 iPad 相機掃描下方 QR Code，點畫面上方跳出的網址。
3
開始使用
進入首頁後輸入學生代碼。不同學生在同一台 iPad 仍會分開紀錄。
💻 在這台筆電開啟完整版
展示功能：影片、標準音、題目、拼讀規則、學生代碼、學習紀錄與自動補強，都可以透過區域網路使用。
iPad 錄音提醒：這個離線 QR 版本使用區域網路的 http:// 網址。Safari / Chrome 在 iPad 上通常不會把一般區網 HTTP 視為安全來源，因此網頁麥克風可能無法啟用。要展示「錄自己的聲音」功能，建議直接在這台筆電用上面的「完整版」；若未來希望 iPad 也能完整錄音，網站需改為 HTTPS。
正在偵測可供 iPad 連線的網址…
如果 QR Code 掃了卻打不開：先確認 iPad 與筆電真的在同一個網路；若 Windows 出現防火牆詢問，請允許「私人網路」。必要時可執行資料夾內的 2_ALLOW_TABLET_ACCESS.bat。
