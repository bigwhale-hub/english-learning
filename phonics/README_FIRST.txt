Phonics Learning System - Offline Tablet Demo v3.2

HOW TO START
1. Extract this ZIP completely on a Windows laptop.
2. Connect the laptop and iPad to the same Wi-Fi, or turn on Windows Mobile Hotspot and connect the iPad to it.
3. Double-click: 1_START_TABLET_DEMO.bat
4. If Windows shows a security warning, choose Run.
5. Keep the PowerShell window open.
6. A launcher page will open in the laptop browser and show one or more QR codes.
7. Scan a QR code with the iPad Camera app and open the link.
8. On iPad over local HTTP, microphone recording is unavailable; the site automatically uses oral-practice mode so exercises can continue.

IF THE IPAD CANNOT CONNECT
Run: 2_ALLOW_TABLET_ACCESS.bat
Then run 1_START_TABLET_DEMO.bat again.
